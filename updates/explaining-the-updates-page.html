Ok, but what is this page?

If you didn't realize it already, everything on the updates page is procedurally generated. I wrote down every single person, place, food, and random thing I could think of until I had like 100 of each. The page then makes the life updates by pulling randomly from those lists. This project was heavily inspired by random tables in old-school-revival tabletop RPGs. Like how in those RPGs you meet an old man, but he has two random traits and the mixing of those traits creates an interesting charater. So instead of a generic old man you meet a... former poet who... hates birds. Boom. Suddenly this randomly rolled NPC has a lot of character. That's what I orginal conceived this page as; two random results, or multiple results together, might tell a story. I also made this page because I think hyper-specific innane life updates is a really funny premise.

As I filled out the tables I started having more and more fun coming up with goofy entries. Actually I think this project has become a funhouse-mirror version of my brother's beloved brainwaves page where he posts random thoughts that come into his head. Whereas his page is full of genuine, hand crafted, entries, my page uses a curated list of entries to create things I didn't think of.

When writing entries I kept everything in the realm of possibility or things I've already done. (If you see something weird you should 100% ask me about it.) I think this whole excercise is much funnier if I'm lying about really mundane things I've done, like I might've actually met my sister for coffee, but it's pretty funny that I'd lie about it. One of my friends also pointed out this page also works as a parody of para-social relations; yeah I guess it works like that. I think these entires all being in the realm of possibility doesn't detract from it's ability as parody, so yeah it's commentary sure.

You can actually see all the code on my Github Page, please don't actually look at my code on there though. I got really frustrated writing the code partway through the project so now about 70% of this project is horribly structured code written by LLMs like ChatGPT. Honestly if I could do it all over again I'd rather have written the whole thing by hand because the codebase is so unintelligible at this point I kinda need the LLMs to help whenever I want to make a change. That's kinda a bleak way to end this explanation, but that might be the biggest thing I learned about coding this project: if you rely on LLMs to write your code, you'll be even more reliant on them to maintain it.
