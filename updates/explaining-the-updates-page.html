Ok, but what is this page?

If you didn't realize it already, everything on the updates page is procedurally generated. I wrote down every single person, place, food, and random thing I could think of until I had like 100 of each. The page then makes the life updates by pulling randomly from those lists. This project was heavily inspired by random tables in old-school-revival tabletop RPGs. Like how in those RPGs you meet an old man, but he has two random traits and the mixing of those traits creates an interesting charater. So instead of a generic old man you meet a... former poet who... hates birds. Boom. With two random results we now have a weirdly fleshed out character. you might encounter an old man, but then you roll on the table to see the old man is NPC, who might be super generic, except the GM rolls on the table and see the old man is a... former poet who... collects birds. Suddenly that randomly rolled NPC has a lot of character. What do those two things tell you about him? This page is supposed to work on the same principle; two random results on the same entry might tell a story, or multiple results together might tell a story. I also made this page because I think hyper-specific innane life updates is a really funny premise.

As I started filling out more of the tables I started having a lot of fun coming up with more and more goofy entires. Actually I think this project has become a funhouse-mirror version of my brother's beloved brainwaves page. On that page he posts funny, hand-crafted, idiosyncratic thoughts. Whereas on this page each individual entry on the tables is handcrafted, but the order and context of each entry is random. And honestly, nowadays whenever I have a funny thought I try to add it to tables in some way, so I imagine the content on each page is actually written in a similar way.

When writing entries I kept everything in the realm of possibility or things I've already done. (If you see something weird you should 100% ask me about it.) I think this whole excercise is much funnier if I'm lying about really mundane things I've done. One of my friends also pointed out this kinda works as a commentary on para-social relationships. Like, I'm giving freakingly frequent updates on mundane things in my life, and yeah keeping everything in the realm of possibility I think also emphasizes that side of it. Yeah I think it is kinda commentary on that sure.

You can actually see all the code on my Github Page. Please don't actually look at my code on there though. I got really frustrated writing the code partway through the project so now about 70% of this project is horribly structured code written by LLMs like ChatGPT. Honestly if I could do it all over again I'd rather have written the whole thing by hand because the codebase is so unintelligible at this point I kinda need the LLMs to help whenever I want to make a change. That's kinda a bleak way to end this explanation, but that might be the biggest thing I learned about coding this project: if you rely on LLMs to write your code, you'll be even more reliant on them to maintain it.
