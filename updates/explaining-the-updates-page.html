Ok, but what is this page?

If you didn't realize it already, everything on the updates page is procedurally generated. I wrote down 100 people, 100 places, 100 food stuffs, and 100 concepts and the page then makes the updates by pulling randomly from those lists. This project was inspired by random tables in OSR tabletop RPGs. Like how in those RPGs you meet an old man, but he has two random traits and the mixing of those traits creates an interesting charater. So instead of a generic old man you meet a... former poet who... hates birds. Boom. Suddenly this randomly rolled NPC has a lot of character. My hope is these results might tell a story when put together: like "ate bad soup" one day and "looked up recipes for mashed potatoes" the next. I also made this page because I think hyper-specific innane life updates is a really funny premise.

I ended up having a lot of fun making goofy entries. With time I think this has become a funhouse-mirror of my brother's beloved brainwaves page. But whereas his page is funn of genuine, handcrafted entires, my page is curated randomness. Frankly his page is funnier than mine though.

When writing entries I kept everything in the realm of things I've actually done. (If you see something weird you should 100% ask me about it.) I think this whole excercise is much funnier if I'm lying about really mundane things instead of inventing bizarre fantasies. Like, I might've actually met my sister for coffee, but it's pretty funny that I'd lie about it. One of my friends also pointed out that a page of frequent, hyper specific, fictional life updates could be a commentary on parasocial relationships—yeah I guess it works as that. So yeah, it's commentary, sure.

You can actually see all the code on my Github Page, please don't actually look at my code on there though. I got really frustrated writing the code partway through the project so now about 70% of this project is horribly structured code written by LLMs like ChatGPT. Honestly if I could do it all over again I'd rather have written the whole thing by hand because the codebase is so unintelligible at this point I kinda need the LLMs whenever I want to make a change. That's kinda a bleak way to end this explanation, but that might be the biggest thing I learned about coding this project: if you rely on LLMs to write your code, you'll be even more reliant on them to maintain it.
