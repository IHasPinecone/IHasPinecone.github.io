MTG Set Linker Rules

1. Objective: Alternate turns naming MTG cards linked by shared sets.

2. Centered Card Nodes: Each card displays its name on the left and art image on the right.

3. Connecting Set Node: Between two cards, a connecting box lists all shared sets with checkmark indicators (e.g. Alpha ✔ ✔ ◯).

4. The 3-Strike Rule:

  • Each set can be used as a connection maximum 3 times across the game.
  • When a valid connection is made, all shared active sets earn a checkmark ✔.
  • Once a set reaches 3 checkmarks (✔ ✔ ✔), it is exhausted and cannot be used to establish future connections.
  • To play a card, it must share at least ONE set with fewer than 3 checkmarks with the previous card.
